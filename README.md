# Make GTA 6 — Block Dodger with a Wanted Level

A small 2D canvas game built for the make.fun GTA 6 bounty: dodge falling blocks,
catch coins, and now outrun the police — every collision with a police car raises your
wanted level by one star (up to five), while a quiet stretch lets the heat cool down.

[![gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/c/gta6-01)
[![rank](https://make.fun/badge/gta6-01/Zikri167/makefun-gta6-01/rank.svg)](https://make.fun/c/gta6-01)
[![reward](https://make.fun/badge/gta6-01/Zikri167/makefun-gta6-01/reward.svg)](https://make.fun/c/gta6-01)

Play it with `node serve.ts`, then open http://localhost:8080. Move with ← → or A D,
pause with P. Built from the make.fun starter: the game is plain static files under
`game/`, and `main.ts` hands it in as `/output` with `dossier.json`.
